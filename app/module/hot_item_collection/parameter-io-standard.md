# 爆款采集模块参数输入输出规范

## 适用范围

本文档用于定义 `app/module/hot_item_collection` 模块统一的参数输入与输出格式。

本文档只描述数据结构、字段类型、必填规则和填写约束，不描述具体业务流程或代码实现。

## 基本约定

- 本模块不接收输入参数。
- 输出必须符合调用方约定的数据格式或文档格式。
- 字段名使用英文驼峰命名，并与本规范保持一致。
- 说明性文本必须使用简体中文。
- 可选数组字段没有数据时使用空数组 `[]`，不使用 `null`。
- 可选字符串字段没有数据时使用空字符串 `""`，不使用 `null`。
- 时间字段统一使用 `yyyy-MM-dd HH:mm:ss` 格式。

## 输入规范

### 输入参数

本模块无输入参数。

### 输入校验规则

1. 调用本模块时不需要传入请求体。
2. 如果调用方必须传入请求体，请使用空 JSON object：`{}`。
3. 除空 JSON object 外，不应传入任何字段。

## 输出规范

### 输出类型

| 字段 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `待确认` | `待确认` | 待确认 | 待确认 | 待确认 |

### 输出校验规则

1. 输出内容必须符合本模块后续定义的输出格式。
2. 输出内容不得虚构输入或采集来源中不存在的数据。
3. 输出内容中如需保留无法确认的信息，应使用 `待确认`。
